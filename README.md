NEON FOLIO is an offline multi-panel GTA-style cover art editor that exports PNG posters in three common social sizes: 1080×1080, 1080×1350, and 1920×1080.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

To try the app locally:

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
